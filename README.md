# Hoeve Beheer – Home Assistant add-on

Add-on repository voor de beheer-app van Hoeve Wetermans.
Installeren: Home Assistant → Instellingen → Apps → App store → ⋮ → Repositories →
voeg `https://github.com/coesjanssen-lab/hoeve-beheer-addon` toe → installeer **Hoeve Beheer**.

Deze repository bevat alleen code. Alle gegevens blijven op de eigen Home Assistant.
